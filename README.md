🤖 SigmaGPT - AI Assistant<br>
[Use SigmaGPT 🚀](https://sigmagpt-frontend-1odj.onrender.com)

SigmaGPT is a full-stack AI assistant built using the MERN stack. It allows users to interact with an AI model and manage multiple conversations.<br>

✨ Features<br>

💬 Multiple Chat Threads – Create and manage separate conversations.<br>
🔐 User Authentication – Secure login and registration using JWT and Bcrypt.<br>
👤 User-Specific Chats – Users can access and manage their own conversation history.<br>
🗄️ Persistent Storage – Store users and conversations using MongoDB.<br>
⚡ Responsive Interface – Built with React for a smooth user experience.<br>

⚙️ Implementation details<br>

* Integrated Google Gemini API for AI-generated responses.
* Implemented JWT-based authentication and authorization
* Used Bcrypt for secure password hashing
* Designed a thread-based chat system for organizing conversations
* Built REST APIs using Express.js
* Stored user data and conversations in MongoDB
* Used Axios for communication between frontend and backend

🛠️ Technologies

* Frontend: React.js, JavaScript, HTML, CSS, Axios
* Backend: Node.js, Express.js
* Database: MongoDB
* Authentication: JWT, Bcrypt
* AI: Google Gemini API
* Deployment: Render
